# AgriAssist — Professional GitHub Pages Version

This is the redesigned static version of the AgriAssist academic project.

## Why this version works on GitHub Pages

GitHub Pages serves static files, so this version uses:
- `index.html`
- `style.css`
- `script.js`

There is no Flask backend dependency for the deployed demo.

## Deploy

1. Replace the files in your `AgriAssist-AI` repository with these three files.
2. Commit and push.
3. In GitHub open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.

Your existing Pages URL will remain:

`https://maheswar6191-stack.github.io/AgriAssist-AI/`
